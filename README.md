# FLOCK

自律的に泳ぐイワシの群れに、指で触れたり、障害物を置いたり、餌をまいたりして、群れの反応を観察する3Dシミュレータです。スマホ向けで、ブラウザで開くだけで遊べます。

**▶ 遊ぶ：** https://shimeji-lab.github.io/flock/

## 遊び方

| モード | できること |
|---|---|
| 触れる（手） | 触れた所から魚が逃げ、その動きが群れに広がります |
| 触れる（餌） | タップした所に餌をまくと、魚が群がって食べます |
| 障害物 | 浮き玉や岩の柱を置き、群れがよけて分かれ、また集まる様子を見られます |
| 観察 | 魚をタップして色を付けたり、ドラッグで視点を回したりできます |

- 2本指で拡大縮小・視点回転、設定（⚙）から目印（海底のマス目・岩・スケールバー）や成長モードを切り替えられます。
- パソコンでは、ホイールで拡大縮小、右ドラッグで回転、Space で一時停止、1・2・3 でモードを切り替えられます。

画面の魚は人工的なモデルで、実際の魚の生態を厳密に再現したものではありません。

## 開発

```bash
npm install                      # テスト用（three@0.128.0）
npm test                         # 群れエンジンの自動テスト
python3 tests/browser/smoke.py   # 画面の動作確認（Playwright が必要）
python3 tools/build.py 0.16      # src/ から index.html と releases/flock_v0.16.html を作る
```
